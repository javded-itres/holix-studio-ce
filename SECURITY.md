# Security

This repository is a **landing page and installer script** for the Holix agent.

- Vulnerabilities in **Holix** (CLI, TUI, gateway, messengers):  
  [javded-itres/Holix](https://github.com/javded-itres/Holix/security)
- Issues with **this installer** (`scripts/install.sh`): open a private note via GitHub Security Advisories on this repo, or an issue without secrets.
- **Holix Studio Cloud** (hosted product): do not file Cloud bugs or leak customer data here. Use holix-studio.ru support.

Never paste API keys, license keys, or `.env` files into issues.
