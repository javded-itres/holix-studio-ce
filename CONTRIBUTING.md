# Contributing

This repository is a **landing page and installer**, not the Cloud IDE source.

## Welcome here

- Fixes to `scripts/install.sh`
- README / screenshot / wording
- Issue templates

Open a PR against `main`. Keep commits small.

## Not here

| Topic | Where |
|-------|--------|
| Holix agent, CLI, Telegram, gateway | https://github.com/javded-itres/Holix |
| Cloud Studio (teams, billing, license) | holix-studio.ru / private product repo |

Do not send Cloud source trees or license keys in issues.
